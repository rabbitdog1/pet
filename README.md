# Paimon Pet

Codex-compatible animated pet inspired by Paimon.

## Files

- `pets/paimon/pet.json` - pet manifest
- `pets/paimon/spritesheet.webp` - final 8x9 animated spritesheet
- `qa/paimon/contact-sheet.png` - visual QA contact sheet
- `qa/paimon/review.json` - frame extraction QA
- `qa/paimon/validation.json` - atlas validation

The packaged pet is also installed locally at:

`C:\Users\username\.codex\pets\paimon`
